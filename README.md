# Poker Host + Max Bot

Развлекательный Texas Hold'em.

- **Веб-приложение** — панель ведущего + красивый стол (транслируешь в Zoom)
- **Бот в Max** — раздаёт карты в личку и принимает действия игроков

Игроки общаются **только с ботом в Max**. В Zoom только смотрят трансляцию.

---

## 1. Запуск веб-приложения

```bash
cd poker-app/backend
npm install
npm start
```

Открой http://localhost:3000

1. Создай стол
2. Скопируй **ID игры** (он понадобится боту)

---

## 2. Запуск бота Max

```bash
cd poker-app/bot
npm install
```

Запускай так (подставь свой GAME_ID):

```bash
GAME_ID=твой_id_игры MAX_TOKEN=твой_токен node max-bot.js
```

**Важно:** токен, который ты прислал ранее, лучше перевыпустить в настройках бота Max.

---

## 3. Как играют

1. Игрок находит твоего бота в Max
2. Пишет: `/join Вася` (ник точно как в Zoom)
3. Бот подтверждает посадку
4. Ты в веб-приложении жмёшь **«Раздать карты»**
5. Каждому игроку в личку Max приходят его 2 карты
6. Когда ход игрока — бот сам пишет ему доступные действия
7. Игрок отвечает: `fold` / `check` / `call` / `raise 50` / `allin`
8. Стол в веб-приложении обновляется, ты транслируешь его в Zoom

---

## Команды бота (для игроков)

| Команда              | Что делает                  |
|----------------------|-----------------------------|
| `/join Ник`          | Сесть за стол               |
| `fold` / `сброс`     | Сбросить карты              |
| `check` / `чек`      | Проверить                   |
| `call` / `колл`      | Уравнять                    |
| `raise 50` / `рейз 50` | Поднять до суммы          |
| `allin` / `вабанк`   | Ва-банк                     |

## Переменные окружения

- `GAME_ID` — ID игры из веб-приложения
- `MAX_TOKEN` — токен бота Max
- `SERVER_URL` — адрес сервера (по умолчанию http://localhost:3000)
- `BOT_SECRET` — секрет (по умолчанию poker-bot-secret)
